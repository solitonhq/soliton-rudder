# Getting help

- **Using the app**: start with [Getting started](docs/GETTING-STARTED.md), the [User guide](docs/USER-GUIDE.md) and
  [Troubleshooting & FAQ](docs/TROUBLESHOOTING.md).
- **Something is broken**: [open a bug report](https://github.com/solitonhq/soliton-rudder/issues/new?template=bug_report.yml)
  with your version (*Settings → About*), macOS version and the error text. Remove secrets and private hostnames first.
- **An idea or a question**: use [Discussions](https://github.com/solitonhq/soliton-rudder/discussions) or a feature request.
- **A security problem**: do **not** open a public issue; follow [SECURITY.md](SECURITY.md).

This is a community project without a support contract or response-time guarantees. Maintainers answer when they can, and
a well-described, reproducible report is the fastest way to a fix.
